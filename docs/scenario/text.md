# Auto Encore 文面一式（最小版 v1.0）

3行要約: ①世界観=閉店後カラオケ店「ミュート」地下の伴奏工房 ②注文1〜3の文面(texts形式) ③ボイス台本16本(決まり台詞のみ)
担当: fumino / 日付: 2026-11-02 / 状態: 最小版 v1.0(PR提出。レビュー待ち) / 実在曲・デュエマ要素なし(全て架空)
文字組: 会話は1行32字×3行(最大96字/枠)。ボイス文は1〜2秒(目安12字前後、最大20字)

## 1. 世界観(固定)

- 舞台: カラオケ店「ミュート」。閉店後の地下に、お客が入れた曲の伴奏を音符パーツで組み立てる工房がある。
- 主人公: 見習い職人(名前なし・プレイヤー)。注文票どおりの演奏を、ベルトと機械の並べ方で自動化する。
- 店の合言葉: 「音は止めても、灯りは消さない」(店名ミュート=消音への、ささやかな反語)。タイトルや店内アナウンスで使う。
- 用語: 注文票 / 見習い / 伴奏 / 回収箱 / Encore!(合格+特別) ※表記はscenario-handoff-templates.mdの統一表に従う

## 3. 注文文面(JSON texts形式。キーは3-8例に合わせる)

### 注文1「開店前の試し弾き」 / 小暮店長

- intro: 「開店前に、二つの音を交互に流せるようにしてほしいんだ。」(26字)
- tutorial: 「合流機は、左右から来た音を順番に一本へまとめます。」(24字)
- result.encore: 「いいね。これなら朝から流せるよ。」
- result.pass: 「ちゃんと流れてる。もう少し詰められそうだ。」
- result.fail: 「音が混ざってしまったみたい。もう一度見てみよう。」
- 組合せ反応(ルールベース): 速度金のみ=「速いね。急ぎの日は助かる。」/ コスト金のみ=「無駄のない並べ方だ。お金も助かる。」/ 正確さ100%のみ=「順番はきっちり。まずは安心だ。」/ New!=「前より良くなったね。」

### 注文2「ハモりの仕分け」 / ひなた

- intro: 「ド、ソ、ミが混ざってて…高い音と低い音を、分けてもらえますか?」(33字→2行に分割: 「ド、ソ、ミが混ざってて…」/「高い音と低い音を分けてもらえますか?」)
- tutorial: 「仕分け機は、決めた音だけを前へ。ほかは右へ流します。」(26字)
- result.encore: 「すごい!きれいに分かれてます!」
- result.pass: 「ちゃんと分かれてる!ミは…回収箱でいいんですよね?」
- result.fail: 「あれ?低い出口にソが混ざってます…もう一回!」
- 組合せ反応: 速度金のみ=「はやっ!もう終わってる!」/ コスト金のみ=「機械、少ないのに頑張ってますね!」/ 正確さ低=「ミが紛れ込んじゃったみたい…でも惜しいです!」(倹約型の銅止まりへの励まし)/ New!=「前の自分に勝ちましたね!」

### 注文3「サビ前の聴かせどころ」 / ミスズ師匠

- intro: 「ドとミと、ミを上げたソを、ド・ソ・ミ・ソの順で四回まとめて、そのあとソを八つ続けてほしいんだ。」(2行: 「ドとミと、ミを上げたソを、ド・ソ・ミ・ソの順で四回まとめて、」/「そのあとソを八つ続けてほしいんだ。」)※案A（Issue #40）。JSON の intro（小暮店長）と話者が異なるため要確認
- tutorial: 「調律機は音を一段上げる。ただし時間がかかるよ。急ぐなら、二台使いな。」(2行に分割)
- result.encore: 「…今のは、いい音だった。昔の私の解に、少し似てたね。」
- result.pass: 「ふん。形だけは整えたね。もう一歩だ。」
- result.fail: 「ソが足りない。手を抜いたのかい。」
- 前回ベスト比較(ルールベース、師匠のみ):
  - 速度が前回より遅い=「前より遅い。どこで迷ったんだい。」
  - コストが前回より高い=「前より高くついたね。贅沢だよ。」
  - 全指標が前回以上=「前より良くなった。…認めてあげる。」
  - 初回(前回なし)=「初めての音だね。聴かせてもらうよ。」
